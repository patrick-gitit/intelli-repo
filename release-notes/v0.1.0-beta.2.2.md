## Migration and rollback

- Migration: Run the current stable or immutable bootstrap with --repo PATH and --yes. An exact beta.1 installation is migrated by the verified current command; do not invoke its internal update transition manually.
- Rollback: Use intelli-repo update --rollback OPERATION_ID while the named update receipt remains valid.

## Known limitations

- Only the exact immutable beta.1 command is eligible for automatic legacy handoff; altered, unhealthy, or incompatible installations remain on the normal conservative installation path. Dotenv remains Linux-only and stores user-managed values as local plaintext.
