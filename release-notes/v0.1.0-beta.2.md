# Intelli-Repo v0.1.0-beta.2 — Complete runtime foundations

Release date: 2026-08-26  
Release channel: beta

## Highlights

- **Complete core agent capabilities.** Base, wiki, and operator agents now ship their required executable capability baselines.
- **One public documentation source.** The public README and banner are generated from the committed design source.
- **Complete generic wiki scaffold.** New installations create every standard wiki register and preserve user-owned content.
- **Safe beta.1 migration and rollback.** Compatible beta.1 updates backfill missing scaffold paths and preserve later user additions during rollback.
- **Governed GitHub release presentation.** Release notes, checksums, and provenance can be projected into a separately approved GitHub prerelease without allowing the hosting interface to mutate Git refs.
- **Local dotenv secret support on Linux.** Linux users can explicitly select a repository-local .intelli-repo/.env provider, retrieve one named value through a bounded consumer, and check readiness without exposing the value. Windows and macOS support remain unavailable pending future validation.

## Migration and rollback

- Migration: Compatible beta.1 installations backfill only missing generic wiki paths.
- Rollback: Use intelli-repo update --rollback OPERATION_ID while the receipt remains valid.

## Known limitations

- The beta compatibility contract may change; dotenv support is Linux-only and stores user-managed values as local plaintext; GitHub Presentation remains separately approval-gated and follows verified Git publication.
